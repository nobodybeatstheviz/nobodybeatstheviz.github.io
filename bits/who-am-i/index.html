Who am I?

On Tableau Cloud, “I” was never a question. You were the one at the keyboard; the filters were the ones you dragged. On Tableau Next, I asked the agent how many home runs I'd seen and it said none. Then it called that a unique insight. The prose was fluent and wrong, and nothing in it told you why. The query underneath did.

#What happened

Tableau Next reads the Salesforce Data 360 semantic model directly. There was nothing to rebuild: the Keeping_Score model is the Tableau Next semantic model, seven objects, five relationships, the seven governed measures. Tableau Agent came on with one Setup toggle. No template, no wizard.

First question: how many home runs have I witnessed? Zero. “You didn't witness any home runs — a unique insight!” The response carries a troubleshooting field, and in it is the exact structured query the agent sent to the semantic engine. That query had a filter I never asked for: attendee_key = <my Salesforce user id>. It had resolved “I” to the running user's id and filtered the attendee table to it. On a one-person model that is always zero. Confidently.

The fix is business preferences on the model: a short text, stored with the semantic model, saying what “I” and “my” mean here. Written headlessly through the hosted MCP, kept as source in git. Asked again: 400 home runs, 178 games. Four of four golden questions after. Seven of seven through the MCP's semantic-query tool, which made Tableau Next the fifth surface in the parity scorecard.

#Two eras of Tableau

On Tableau Cloud, the classic product, the marts were published as five data sources and one relationship model with no GUI, and the seven questions ran through the query service: seven of seven. Visual, descriptive, yours. On Tableau Next, the same model is governed-metric-and-agent: you don't drag a filter, you tell the model what your words mean and the agent binds the question to a governed field.

A cross-table row-level formula that Data 360 silently fanned out to 281 rows, Tableau Cloud refused outright: “only one upstream base table.” Home runs and Hall of Famers in one query worked on Tableau Cloud where Data 360 threw NO_PATH, because the Tableau model has one more edge, not because the semantics differ. Same definitions, different engines, and the differences are in the joins each one is willing to walk.

This is Tableau Next as a query and agent surface over a Data 360 model, plus the one chart above, built for this run. No dashboards. The org it lives in is a scratch org that expires 2026-10-03, so everything here lives in git or evaporates. That was the forcing function.

#What it taught me

  1. Read the query, not the prose. The prose said zero and sounded certain. The query showed the filter. Every agent surface in this run was measured on whether it shows you the query it ran, and this one does.
  2. The fix lives on the model. Any personal-data model on Tableau Next needs business preferences saying who “I” is. Where does your knowledge of the data go in an agentic stack? Here is one of the places: a paragraph on the semantic model that every question passes through.
  3. Tableau Cloud answered seven of seven too. The new era didn't replace the old one's answers; it changed who asks and how the meaning gets attached.
