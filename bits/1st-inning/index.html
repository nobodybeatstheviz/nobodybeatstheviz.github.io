THE BAR CHART AN AGENT MADE

Can you trust the number on the chart?

You have made this chart a thousand times. Years across the bottom, a count up the side, sort by year, done before the coffee cools. This one you didn't make. An agent wrote the workbook as XML, a server checked it line by line, and it published to Tableau Cloud without a browser being open. The bars say 400. The only question worth asking is the one you'd ask of anyone else's chart: how do I know that's right?

#What happened

The spec was five lines: measure, by what, sort, title rule, color. From it the agent emitted a .twb, which is a workbook as XML, the same file Tableau Desktop writes when you hit save. The Tableau MCP server took the file, validated it server-side and returned line-level errors when it was wrong, and published it when it wasn't. The receipt is a PNG and a CSV that sums to 400. If the CSV doesn't sum to 400, the script exits and nothing publishes.

Two eras of the grammar showed up on the way. Tableau's newest strict workbook schema is blocked by two errors in Tableau's own published schema, and no content fixes them. The generator writes the older grammar instead, which is the one Tableau 2026.1 itself still writes when you download a workbook. That was measured, not assumed. The server's verdict on upload is the gate, not the local schema.

Where headless stopped: nowhere. The red bars took. The font rule was accepted by the server and didn't show in the render, which is the ceiling, not the floor. The floor is the number and the sort, and they held.

#How you know it's right

Not because the agent said so. The 400 on this chart is home runs witnessed, one governed definition written down once in dbt: a play in a game I attended whose event code is 23. Every bar is that definition grouped by year. And the same definition, asked of five other engines through each one's own semantic layer, comes back 400 every time. A harness asks the question of all six and diffs the answers. On 2026-09-06 it read 42 of 42.

So the chart is the photo. The definition is the contract. The harness is the scorecard that says the number on the photo is the same number everywhere else. That's the whole run in one sentence, and it's why the 1st inning is a bar chart and not an agent: this is where you're standing, and the question is the one you already know how to ask.

The honest line: it's one workbook, one sheet, personal data at demo scale. No dashboards were built. The discipline is the point, not the volume.

#What it taught me

  1. The chart was never the hard part. An agent can make it in one pass from five lines. What it can't do is decide what a home run is, and that decision is the only thing on this page that took judgment. It lives upstream of every tool, in the 2nd inning.
  2. Validation belongs to the server, not the author. A local schema said the strict grammar was fine. The server said no, with a line number. Trust the door you're publishing through, not the file you're holding.
  3. Next to Tableau, never instead of. The same chart gets remade on every door the rest of the run walks through, Tableau Next and Streamlit and Databricks and Looker Studio and a plain Claude page. Tableau made it first, and the run measures the rest against it.
