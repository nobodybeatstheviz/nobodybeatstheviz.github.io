#The game notes

My grandfather taught me to keep score. Pencil. Card. 6-4-3. That scorecard was the first clean dataset I ever held. The back of a baseball card was the same plays, added up. Row-level in one hand, aggregate in the other. I didn't know either word yet.

That was 1984. I haven't stopped. 178 games, every one checked against the Retrosheet play-by-play, modeled in dbt. This year I took seven questions any fan would ask and ran them through every tool you're being told changes everything. Tableau. Tableau Next. Agentforce. Data 360. Snowflake. Databricks.

Every one of them wants to keep score for you now. Some got it right. Some got it wrong with a straight face. I kept score on them.

Claude Code had the seat next to me the whole way. This site's built with the same tools it talks about.

How to keep score → the seven questions, the parity harness, how to read a trace.
